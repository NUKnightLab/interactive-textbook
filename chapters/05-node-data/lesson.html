Chapter 5: Node.js

Node.js is a JavaScript runtime that runs in your terminal. We use it here for data analysis the same way you might use Python or R: load a CSV, manipulate it, print results.

What's in analyze.js

Open analyze.js on the right. It:

  1. Reads iris.csv from disk.
  2. Loads it into an arquero table.
  3. Prints the first 5 rows.
  4. Groups by species and computes per-group counts and means.
